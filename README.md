# Milani Soluções Digitais

Site institucional da Milani Soluções Digitais, hospedado no Netlify.

## Publicação

O site utiliza `index.html` e `logo-milani.png` na raiz do repositório. Para publicar automaticamente, conecte este repositório ao projeto Netlify existente e selecione a branch `main` e o diretório de publicação `.`.

> A plataforma de atendimento ainda é demonstrativa e não deve armazenar dados reais de clientes.
